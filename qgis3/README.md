# MSPA for QGIS — moved

The QGIS plugin is now maintained in [`qgis/`](../qgis/) and supports both
QGIS 3.16+ and QGIS 4 with one package.

This folder only keeps `VERSION` so that plugins installed from the earlier
`qgis3-v2.1.x` releases still receive their update notice. New installations
should use the ZIP from the latest [`qgis-v*` release](https://github.com/vogtpet/MSPA-plugins/releases)
and follow [`qgis/README.md`](../qgis/README.md).
